# Mapeo de campos de anexos

Este documento relaciona cada clase con el archivo Word que originó sus propiedades. Solo se mapearon campos capturables de las rejillas; se excluyeron valores de ejemplo en azul y filas usadas únicamente como encabezados de sección.

`DocumentosSeleccionados` es un campo adicional solicitado para todas las clases y no proviene de una rejilla.
